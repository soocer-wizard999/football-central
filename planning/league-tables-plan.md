# Football Central — League Tables Plan

## Purpose
Show fans the latest standings for football competitions.

## Table Columns
- Position
- Club badge
- Club name
- Matches played (P)
- Wins (W)
- Draws (D)
- Losses (L)
- Goals for (GF)
- Goals against (GA)
- Goal difference (GD)
- Points (PTS)

## Competition Filters
- Premier League
- La Liga
- Serie A
- Bundesliga
- Ligue 1
- MLS

## Table Features
- Sort teams by points
- Show recent form
- Highlight qualification positions
- Show relegation positions
- Display the current season

## Future Features
- Automatic standings updates
- Previous season tables
- Home and away standings
- Club profile links
